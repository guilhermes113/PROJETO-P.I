PAra subir meu novo repositório, primeiro criar um Repositorio no GitHUB, depois ir no meu projeto e abrir um terminal na paasta raiz.

git init -> inicia

git add. -> salva todos os arquivos no próximo commit.

git config --global user.email "guilhermesanches248@gmail.com" -> confirma o email

git config --global user.name "guilhermes113" -> confirma o nome

git commit -m "Commit inicial do projeto" -> inicia o commit

git remote add origin URL_DO_SEU_REPOSITORIO_AQUI

git branch -M main
git push -u origin main


…or create a new repository on the command line

echo "# PROJETO-P.I" >> README.md
git init
git add README.md
git commit -m "first commit"
git branch -M main
git remote add origin https://github.com/guilhermes113/PROJETO-P.I.git
git push -u origin main


…or push an existing repository from the command line

git remote add origin https://github.com/guilhermes113/PROJETO-P.I.git
git branch -M main
git push -u origin main
